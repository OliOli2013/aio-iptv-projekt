satellites.xml — aktualizacja i problemy ze skanowaniem

Plik satellites.xml zawiera definicje satelitów i transponderów. Po jego podmianie wykonaj restart GUI lub tunera, żeby Enigma2 używała nowych danych przy skanowaniu.

  • Najczęstsza lokalizacja: /etc/tuxbox/satellites.xml.
  • Przed podmianą zrób kopię poprzedniego pliku.
  • Jeżeli skanowanie dalej pokazuje poprzednie dane, przeładuj GUI.
Kopia zapasowa
cp /etc/tuxbox/satellites.xml /etc/tuxbox/satellites.xml.bak
Sprawdzenie pliku
ls -l /etc/tuxbox/satellites.xml
Restart GUI po podmianie
init 4 && sleep 2 && init 3
