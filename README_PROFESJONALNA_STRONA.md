# AIO-IPTV.pl — pełna wersja profesjonalna

Wersja przygotowana na bazie aktualnej strony z zachowaniem wszystkich plików, projektów, aplikacji, systemów i poradników.

## Najważniejsze nowe elementy

- nowe centrum pobierania z filtrami, statusem wersji, rozmiarem i SHA-256;
- centrum zgodności dla Enigma2, Androida i Windows;
- generator kompletnego zgłoszenia błędu;
- przebudowana strona główna oparta na zadaniach użytkownika;
- ujednolicone menu i metadane projektów;
- PWA, tryb offline, manifest, service worker, sitemap i robots.txt;
- rozszerzone SEO i Open Graph;
- opcja ukrycia monitu wsparcia na 7 dni;
- filtry na stronach wtyczek i poradników.

## Publikacja

Wgraj całą zawartość archiwum do katalogu głównego repozytorium GitHub Pages, zastępując dotychczasowe pliki. Katalog `.git` nie jest częścią paczki.
