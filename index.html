AIO Panel v9.1.1 (Enigma2) — nowy interfejs (Sidebar + Content, cyber-blue), nowa zakładka Skins/Skórki i poprawiona stabilność poleceń systemowych. Kompatybilna z wszystkimi systemami Enigma2 (Py2/Py3).

⬇️ AIO Panel 9.1.1
AIO Panel v9.1.1 jest dostępny

Wtyczka dla Enigma2 (Python 2/3). Na stronie znajdziesz instalację, opis zmian i narzędzia towarzyszące (konfiguratory, porównywarki, poradniki).

Najważniejsze zmiany w 9.1.1

  • Naprawa losowego braku opisów/opcji w menu na Python 2 (OpenATV 6.4 / VTi).
  • Wymuszona poprawna konwersja typów tekstu w listach GUI (Py2: str/UTF-8 bytes, Py3: str) — koniec z „<not-a-string>” i znikającymi nazwami.
  • Dodane instalatory wtyczek: ChocholousekPicons, CIEFP Oscam Editor, FilmXY, FootOnsat oraz e‑stralker (feed/opkg).

Instalatory wtyczek (dodane w 9.1.1)

Komendy do uruchomienia w terminalu tunera (telnet/SSH):

ChocholousekPicons 
wget -qO- --no-check-certificate 'https://github.com/s3n0/e2plugins/raw/master/ChocholousekPicons/online-setup' | bash -s install
CIEFP Oscam Editor 
wget -q --no-check-certificate 'https://raw.githubusercontent.com/ciefp/CiefpOscamEditor/main/installer.sh' -O - | /bin/sh
FilmXY 
wget -q --no-check-certificate https://raw.githubusercontent.com/Belfagor2005/filmxy/main/installer.sh -O - | /bin/sh
FootOnsat 
wget https://raw.githubusercontent.com/fairbird/FootOnsat/main/Download/install.sh -O - | /bin/sh
e‑stralker (feed) 
opkg update && opkg install enigma2-plugin-extensions-estalker
Archiwum: zawartość poprzedniej strony (bez zmian)zachowane
