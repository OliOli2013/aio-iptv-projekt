SPOŁECZNOŚĆ AIO — INSTRUKCJA URUCHOMIENIA
Wersja: 2026-07-25 community1

WAŻNE
GitHub Pages przechowuje wyłącznie stronę. Konta, posty, komentarze i zdjęcia wymagają bazy Supabase.
Paczka jest już przygotowana do użycia z tym samym projektem Supabase, który obsługuje AI Chat:
https://pynjjeobqzxbrvmqofcw.supabase.co

Nie umieszczaj w GitHubie service_role key ani prywatnych kluczy. Użyty klucz anon jest przeznaczony do frontendu,
a dostęp do danych ograniczają polityki Row Level Security zawarte w pliku SQL.

============================================================
KROK 1 — WGRANIE PLIKÓW NA GITHUB
============================================================

1. Rozpakuj paczkę.
2. Skopiuj całą zawartość do katalogu głównego repozytorium aio-iptv-projekt.
3. Zachowaj katalogi:
   assets/css
   assets/js
   data
   supabase
4. Zatwierdź zmiany w GitKraken i wykonaj Push.
5. Poczekaj na publikację GitHub Pages.

Nowe strony:
- community.html — główna tablica społeczności
- news.html — oficjalne aktualności
- post.html — pełny wpis i komentarze
- profile.html — profil użytkownika
- community-admin.html — panel moderacji
- community-rules.html — regulamin
- privacy-community.html — informacja o prywatności

============================================================
KROK 2 — UTWORZENIE BAZY W SUPABASE
============================================================

1. Wejdź do panelu Supabase.
2. Otwórz projekt: pynjjeobqzxbrvmqofcw.
3. Przejdź do SQL Editor.
4. Wybierz New query.
5. Otwórz z paczki plik:
   supabase/community_setup.sql
6. Skopiuj CAŁĄ jego zawartość do SQL Editor.
7. Kliknij Run.
8. Powinien pojawić się komunikat o poprawnym wykonaniu zapytania.

Skrypt tworzy:
- profile użytkowników;
- posty i oficjalne aktualności;
- komentarze i odpowiedzi;
- reakcje Pomocne / Działa / Dziękuję;
- obserwowanie wpisów;
- powiadomienia;
- zgłoszenia moderacyjne;
- publiczny bucket community-media na zdjęcia;
- Row Level Security;
- limity przeciw spamowi;
- kolejkę zatwierdzania pierwszych wpisów;
- automatyczne usuwanie zdjęć po usunięciu wpisu;
- Realtime dla postów, komentarzy, reakcji i powiadomień.

============================================================
KROK 3 — USTAWIENIA LOGOWANIA
============================================================

W Supabase przejdź do:
Authentication -> URL Configuration

Ustaw:
Site URL:
https://olioli2013.github.io/aio-iptv-projekt/

Redirect URLs — dodaj:
https://olioli2013.github.io/aio-iptv-projekt/community.html
https://olioli2013.github.io/aio-iptv-projekt/profile.html

Następnie przejdź do:
Authentication -> Providers -> Email

Pozostaw włączone logowanie e-mail. Strona korzysta z linku jednorazowego, bez klasycznego hasła.

W ustawieniach szablonu e-mail można zmienić nazwę nadawcy i treść wiadomości na „Społeczność AIO”.

============================================================
KROK 4 — PIERWSZE LOGOWANIE I NADANIE ADMINISTRATORA
============================================================

1. Otwórz po publikacji:
   https://olioli2013.github.io/aio-iptv-projekt/community.html
2. Kliknij „Zaloguj / utwórz konto”.
3. Podaj własny adres e-mail.
4. Otwórz link otrzymany w wiadomości.
5. Wróć do Supabase -> SQL Editor.
6. Otwórz plik:
   supabase/nadaj_admina_i_pierwszy_wpis.sql
7. Zastąp TWOJ-EMAIL@DOMENA.PL adresem użytym do logowania.
8. Uruchom zapytanie.
9. Odśwież stronę Ctrl+F5.

Po nadaniu roli zobaczysz:
- przycisk „Moderacja”;
- możliwość publikowania wpisów oficjalnych;
- możliwość zatwierdzania pierwszych wpisów nowych kont;
- obsługę zgłoszeń;
- przypinanie wpisów;
- blokowanie komentarzy;
- oznaczanie użytkowników jako zaufanych;
- czasowe blokowanie kont;
- nadawanie roli moderatora.

============================================================
KROK 5 — PUBLIKOWANIE OFICJALNYCH AKTUALNOŚCI
============================================================

1. Zaloguj się jako administrator.
2. Otwórz community.html.
3. W formularzu nowego wpisu zaznacz:
   „Opublikuj jako oficjalną aktualność AIO-IPTV.pl”.
4. Wpis pojawi się jednocześnie w:
   - community.html
   - news.html
5. W panelu community-admin.html możesz go przypiąć i zablokować komentarze.

============================================================
JAK DZIAŁA MODERACJA
============================================================

- Zwykły nowy użytkownik: pierwszy wpis trafia do statusu „oczekuje”.
- Administrator lub moderator zatwierdza go w community-admin.html.
- Po oznaczeniu użytkownika jako „zaufany” następne wpisy publikują się od razu.
- Komentarze publikują się od razu, ale obowiązuje limit i możliwość zgłoszenia.
- Konto można zablokować na 7 dni.
- Moderator nie może nadać sobie roli administratora.
- Użytkownicy mogą usuwać własne posty i komentarze.
- Row Level Security uniemożliwia zmianę cudzych treści zwykłym kontom.

============================================================
POWIADOMIENIA
============================================================

Po zalogowaniu ikona dzwonka pokazuje:
- odpowiedzi pod własnym wpisem;
- odpowiedzi na komentarz;
- aktywność w obserwowanym wpisie;
- zatwierdzenie albo odrzucenie wpisu.

Po kliknięciu „Włącz systemowe” użytkownik może zezwolić na powiadomienia przeglądarki.
Powiadomienia systemowe działają, gdy strona jest otwarta lub aktywna w przeglądarce.

============================================================
BEZPIECZEŃSTWO
============================================================

- Nie dodawaj service_role key do data/community_config.json.
- Nie publikuj prywatnych kluczy API.
- Regularnie sprawdzaj zgłoszenia w community-admin.html.
- Zrób kopię bazy Supabase przed większymi zmianami.
- Dostosuj privacy-community.html do własnych danych administratora i ostatecznej konfiguracji.
- Na początku pozostaw zatwierdzanie pierwszych wpisów nowych kont.

============================================================
GDY LOGOWANIE NIE PRZYCHODZI
============================================================

1. Sprawdź folder SPAM.
2. Sprawdź Authentication -> Logs w Supabase.
3. Sprawdź Site URL i Redirect URLs.
4. Sprawdź, czy Provider Email jest włączony.
5. Sprawdź dzienny limit wiadomości e-mail projektu Supabase.

============================================================
TYMCZASOWE WYŁĄCZENIE SPOŁECZNOŚCI
============================================================

W pliku data/community_config.json zmień:
"enabled": true
na:
"enabled": false

Dane pozostaną w Supabase, ale frontend pokaże informację o wyłączonym module.
