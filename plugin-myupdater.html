Updater / diagnostyka

Co robi ta wtyczka?

Updater i instalator dla list kanałów, pikonów, softcamów oraz diagnostyki systemu.

  • Aktualizacja list kanałów i pikonów.
  • Pomoc przy softcamach i rozpoznawaniu dystrybucji.
  • Mechanizmy rozwinięte później w AIO Panel.
  • Paczka Py2/Py3 zależnie od środowiska.
Kompatybilność: Enigma2 Python 2 / Python 3.

Pobieranie

Plik: enigma2-plugin-extensions-myupdater_5.1_all.ipk

Rozmiar: 23.9 KB

Pobierz IPK
Instalacja

Terminal, OpenWebif albo FTP

Najczyściej: pobierz IPK, wgraj przez FTP do /tmp, potem wykonaj instalację z terminala.

FTP + lokalny IPK

  1. Pobierz plik IPK z tej strony.
  2. Połącz się FTP z tunerem.
  3. Wgraj plik do katalogu /tmp.
  4. W terminalu wykonaj:
Instalacja pliku z /tmp
opkg install /tmp/enigma2-plugin-extensions-myupdater_5.1_all.ipk
killall -9 enigma2

Wget z adresu strony

Gdy tuner ma dostęp do internetu, możesz pobrać paczkę bezpośrednio.

Pobierz i zainstaluj
wget -O /tmp/myupdater.ipk https://aio-iptv.pl/pliki/enigma2-plugin-extensions-myupdater_5.1_all.ipk && opkg install /tmp/myupdater.ipk && killall -9 enigma2
