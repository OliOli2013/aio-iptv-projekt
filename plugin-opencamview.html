Kamery IP / RTSP

Co robi ta wtyczka?

Podgląd kamer IP w Enigma2 po RTSP bez ręcznego przerabiania list kanałów.

  • Dodawanie, edycja i usuwanie kamer z poziomu GUI.
  • OK uruchamia szybki podgląd wybranej kamery.
  • INFO / EPG / HELP otwiera tryb MultiView, czyli TV plus kamera w PiP.
  • Eksport kamer do bukietu Enigma2 jako usługi 4097.
  • Eksport kamer do pliku M3U.
  • Wbudowany skaner sieci do szukania kamer w LAN.
Kompatybilność: Enigma2 Python 3, kamery IP z poprawnym adresem RTSP.

Instalacja

Terminal, OpenWebif albo FTP

Najczyściej: pobierz IPK, wgraj przez FTP do /tmp, potem wykonaj instalację z terminala.

FTP + lokalny IPK

  1. Pobierz plik IPK z tej strony.
  2. Połącz się FTP z tunerem.
  3. Wgraj plik do katalogu /tmp.
  4. W terminalu wykonaj:
Instalacja pliku z /tmp
opkg install /tmp/enigma2-plugin-extensions-opencamview_1.3_all.ipk
killall -9 enigma2

Wget z adresu strony

Gdy tuner ma dostęp do internetu, możesz pobrać paczkę bezpośrednio.

Pobierz i zainstaluj
wget -O /tmp/opencamview.ipk https://aio-iptv.pl/pliki/enigma2-plugin-extensions-opencamview_1.3_all.ipk && opkg install /tmp/opencamview.ipk && killall -9 enigma2
