EPG dla IPTV

Co robi ta wtyczka?

Prostsze przypisywanie programu EPG do kanałów internetowych.

  • Aktualna wersja 2.2.1.
  • Pomoc przy kanałach IPTV bez poprawnego EPG.
  • Lekka paczka IPK.
  • Dobra jako narzędzie pomocnicze obok EPG Import.
Kompatybilność: Enigma2 Python 3 / zależnie od obrazu.

Pobieranie

Plik: enigma2-plugin-extensions-simpleiptvepg_2.2.1_all.ipk

Rozmiar: 49.1 KB

Pobierz IPK
Instalacja

Terminal, OpenWebif albo FTP

Najczyściej: pobierz IPK, wgraj przez FTP do /tmp, potem wykonaj instalację z terminala.

FTP + lokalny IPK

  1. Pobierz plik IPK z tej strony.
  2. Połącz się FTP z tunerem.
  3. Wgraj plik do katalogu /tmp.
  4. W terminalu wykonaj:
Instalacja pliku z /tmp
opkg install /tmp/enigma2-plugin-extensions-simpleiptvepg_2.2.1_all.ipk
killall -9 enigma2

Wget z adresu strony

Gdy tuner ma dostęp do internetu, możesz pobrać paczkę bezpośrednio.

Pobierz i zainstaluj
wget -O /tmp/simple-iptv-epg.ipk https://aio-iptv.pl/pliki/enigma2-plugin-extensions-simpleiptvepg_2.2.1_all.ipk && opkg install /tmp/simple-iptv-epg.ipk && killall -9 enigma2
