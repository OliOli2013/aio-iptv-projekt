Instalacja

Wybierz sposób instalacji AIO Panel

Po instalacji lub aktualizacji wykonaj Restart GUI.

AIO Panel — instalacja / aktualizacja z GitHuba
wget -q -O - "https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh?$(date +%s)" | /bin/sh
Instalacja pobranego AIO Panel 17.0.3
opkg install --force-reinstall /tmp/enigma2-plugin-extensions-panelaio_17.0.3_all.ipk
1Pobierz IPKPobierz plik z tej strony na komputer.
2Wgraj do /tmpUżyj FTP/SFTP lub menedżera plików.
3Uruchom komendęWykonaj polecenie instalacyjne w terminalu.
4Restart GUIPo instalacji zrestartuj interfejs Enigma2.
Instalacja pobranego AIO Panel 17.0.3 — DEB
dpkg -i /tmp/enigma2-plugin-extensions-panelaio_17.0.3_all.deb

Plik DEB przeznaczony dla obrazów Enigma2 obsługujących dpkg. Po instalacji wykonaj Restart GUI.
