AIO Panel 16.0.0

Duża aktualizacja projektu. Wersja 16.0.0 przebudowuje techniczne fundamenty AIO Panel, zwiększa bezpieczeństwo źródeł i diagnostyki oraz dodaje wygodniejsze wyszukiwanie i organizację najczęściej używanych funkcji.

AIO Panel 16.0.0 — duża aktualizacja projektu

To nie jest wyłącznie zmiana wyglądu ani dodanie kolejnych pozycji w menu. Duża część pracy została wykonana wewnątrz samego AIO Panel, aby wtyczka była stabilniejsza, bezpieczniejsza i łatwiejsza do dalszego rozwijania.

Najważniejsza zmiana: rozpoczęto odejście od dużego monolitycznego kodu i przygotowano modularny fundament pod kolejne wydania, przy zachowaniu znanego sposobu obsługi AIO Panel.

Przebudowany rdzeń AIO Panel

  • rozpoczęto odejście od dużego monolitycznego kodu
  • wydzielono moduły odpowiedzialne za logowanie, wyniki operacji, rejestr akcji, źródła i diagnostykę
  • przygotowano nową warstwę Action Dispatcher
  • zachowano warstwę kompatybilności ze starszym kodem

Nowy system bezpieczeństwa źródeł

  • rejestr zaufanych źródeł
  • dokładniejsza kontrola adresów pobierania
  • dodatkowa walidacja pobranych skryptów i plików
  • kontrola sum SHA-256
  • rozszerzona ochrona przed potencjalnie niebezpiecznymi poleceniami systemowymi

Wyszukiwarka, Ulubione i Ostatnio używane

  • Wyszukiwarka AIO Panel — szybkie odnalezienie funkcji bez przeglądania wszystkich kategorii
  • Ulubione — własna lista najczęściej używanych narzędzi
  • Ostatnio używane — szybki powrót do niedawno wykonywanych operacji

Health Check i kanały aktualizacji

  • Health Check sprawdza dostępność najważniejszych źródeł AIO bez rozpoczynania instalacji
  • przygotowano kanały aktualizacji Stable / Test
  • łatwiejsze rozdzielenie stabilnych wydań od wersji przeznaczonych do testów

Centralny logger i wyniki operacji

  • nowy centralny logger AIO Panel
  • czytelniejsze informacje diagnostyczne i łatwiejsze wykrywanie przyczyn błędów
  • ograniczenie sytuacji, w których błąd był przechwytywany bez zapisu informacji
  • nowe funkcje mogą zwracać jednoznaczny wynik, błąd, log, wymagany restart GUI lub inne wymagane działanie

Automatyczna konserwacja i pamięć

  • uporządkowany mechanizm automatycznej konserwacji
  • tryby: przy starcie GUI, raz dziennie lub raz na kilka dni
  • funkcja pamięci nie sugeruje już sztucznego „czyszczenia RAM Linuxa”
  • wykonywane są rzeczywiste operacje dotyczące pamięci procesu AIO i plików tymczasowych

Rozbudowany Self-Test i AIO Connect

  • dodatkowa kontrola podstawowych elementów instalacji i wymaganych modułów
  • rozszerzona diagnostyka AIO Connect
  • dodatkowe zabezpieczenia raportów
  • anonimizacja części danych sieciowych
  • raporty pozostają lokalne i nie są automatycznie wysyłane

Aktualizacje i nowy bootstrap instalatora

  • przebudowany mechanizm aktualizacji AIO
  • docelowo jeden pakiet IPK jest właściwym artefaktem instalacyjnym niezależnie od sposobu rozpoczęcia aktualizacji
  • nowy bootstrap instalatora może przygotować wymagane elementy na czystym tunerze i uruchomić instalację właściwego pakietu

Uporządkowane repozytorium i automatyczne testy

Repozytorium GitHub zostało oczyszczone z dużej części historycznych raportów, dokumentów technicznych i plików po wcześniejszych testach. Kod uporządkowano w logiczne katalogi, m.in. core/, data/, ui/, tests/, tools/, docs/ i release/.

  • automatyczne sprawdzanie składni Python
  • kontrola skryptów shell
  • wewnętrzny Self-Test
  • testy regresyjne
  • sprawdzanie poprawności budowania pakietu IPK
Cel wersji 16.0.0: stworzenie fundamentu, dzięki któremu kolejne funkcje można rozwijać bez dalszego powiększania jednego ogromnego pliku źródłowego.

Instalacja i aktualizacja

Po instalacji lub aktualizacji wykonaj restart GUI Enigma2.

Instalacja bezpośrednio z GitHub
wget -q -O - "https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh?$(date +%s)" | /bin/sh

Instalacja pobranego IPK przez FTP

Wgraj plik do /tmp, a następnie wykonaj:

Instalacja IPK
opkg install --force-reinstall /tmp/enigma2-plugin-extensions-panelaio_16.0.0_all.ipk
