AIO Panel 13.0.0 Final

Finalna wersja AIO Panel 13.0.0: poprawki crasha na skinach FHD, bezpieczniejsza obsługa zadań tła, lepsze wykrywanie katalogu aktywnego OSCam oraz nowy instalator OSCam Levi45.

Do czego służy

Finalna wersja AIO Panel 13.0.0: poprawki crasha na skinach FHD, bezpieczniejsza obsługa zadań tła, lepsze wykrywanie katalogu aktywnego OSCam oraz nowy instalator OSCam Levi45.

Plik: enigma2-plugin-extensions-panelaio_13.0.0_all.ipk 204.4 KB

Najważniejsze zmiany w 13.0.0 Final

  • naprawiono crash na skinach FHD, zgłoszony między innymi dla Algare FHD
  • usunięto problematyczne MessageBox(enable_input=False) z zadań tła
  • dodano bezpieczny fallback dla okien MessageBox
  • poprawiono obsługę plików OSCam dla niestandardowych instalacji, szczególnie OSCam jej@n / S4Updater
  • funkcje oscam.dvbapi, oscam.srvid, oscam.srvid2, SoftCam.Key oraz kasowanie hasła wykrywają katalog z aktywnego procesu OSCam
  • przed zmianą plików OSCam tworzone są kopie bezpieczeństwa z datą
  • jeżeli katalog konfiguracji OSCam nie zostanie wykryty jednoznacznie, operacja zostaje przerwana
  • dodano instalator OSCam Levi45 z oficjalnego polecenia Levi45Emulator
  • menu pokazuje uproszczoną nazwę Oscam Levi45 oraz wykryty numer OSCam

Changelog 13.0.0 Final

Skiny FHD i zadania tła

  • naprawiono restart Enigmy przy otwieraniu okna oczekiwania w run_command_in_background
  • zrezygnowano z MessageBox(enable_input=False), który potrafił wywoływać crash na wybranych skinach FHD
  • dodano fallback, dzięki któremu problem skina nie powinien zatrzymywać pracy wtyczki

OSCam i bezpieczeństwo plików

  • poprawiono pracę z niestandardowymi instalacjami OSCam, szczególnie jej@n / S4Updater
  • AIO Panel wykrywa katalog konfiguracji z aktywnego procesu OSCam, zamiast zgadywać ścieżkę
  • przed zmianą plików tworzony jest backup z datą
  • brak jednoznacznej ścieżki oznacza przerwanie operacji ze względów bezpieczeństwa

Nowy instalator

  • dodano Oscam Levi45 w zakładce Softcamy
  • instalator korzysta z oficjalnego polecenia projektu Levi45Emulator
  • w menu widoczna jest uproszczona nazwa oraz wykryty numer OSCam

Zalecenie

  • po aktualizacji wykonaj ręczny Restart GUI
  • przy niestandardowym OSCam sprawdź jego działanie przed użyciem funkcji aktualizacji plików OSCam

Zdjęcia / podgląd

Instalacja przez terminal

Instalator AIO Panel — polecenie podstawowe
wget -q -O - https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Domyślna komenda dla użytkownika.

Instalator AIO Panel — wariant OpenPLi / problemy z GitHub
wget -q -O - --user-agent="Enigma2" -4 https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Użyj tylko gdy zwykłe pobieranie z GitHuba nie działa.

Instalacja pobranego IPK przez FTP

Jeśli pobierasz paczkę ręcznie: wgraj plik IPK do katalogu /tmp, a potem wykonaj instalację w terminalu.

Instalacja IPK z /tmp
opkg install /tmp/nazwa_paczki.ipk
