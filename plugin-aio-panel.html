AIO TEAM • ENIGMA2 • AKTUALIZACJA 04.10.2026

AIO Panel 17.0.0

Centralny panel narzędzi dla Enigma2: instalatory, listy kanałów, dodatki, skórki i aktualizacje. Wersja 17.0.0 dodaje kontrolę poprawności archiwów list przed ich pokazaniem oraz porządkuje cały katalog instalacyjny.

● aktywnie rozwijany Python 2.7 + Python 3 PL / EN IPK all
Pobierz IPK 17.0.0 Instalacja Status projektu
Najważniejsze Co poprawiono Pełna lista zmian Plik i zgodność Instalacja

Najważniejsza zmiana 17.0.0

Panel najpierw sprawdza listę kanałów, dopiero potem ją pokazuje.

Archiwa są weryfikowane przed wyświetleniem użytkownikowi. Dzięki temu puste, błędne lub uszkodzone paczki nie są prezentowane jako poprawna lista do instalacji.

  • mniej nieudanych instalacji list kanałów,
  • ukrywanie uszkodzonych archiwów,
  • lepsze przywracanie poprzedniej listy po błędzie.

Wydanie z 4 października 2026.
