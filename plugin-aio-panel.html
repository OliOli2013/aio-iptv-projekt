AIO Panel 12.0.6

Skumulowana aktualizacja AIO Panel 12.0.6 obejmująca wydania 12.0.4, 12.0.5 i 12.0.6: większa stabilność, bezpieczniejsza instalacja, mniej wymuszonych restartów i pełna zgodność z Python 2 / Python 3.

Do czego służy

Skumulowana aktualizacja AIO Panel 12.0.6 obejmująca wydania 12.0.4, 12.0.5 i 12.0.6: większa stabilność, bezpieczniejsza instalacja, mniej wymuszonych restartów i pełna zgodność z Python 2 / Python 3.

Plik: enigma2-plugin-extensions-panelaio_12.0.6_all.ipk 204.0 KB

Najważniejsze zmiany w 12.0.6

  • krytyczne poprawki stabilności i bezpieczeństwa — mniejsze ryzyko bootloopów
  • blokada uruchamiania instalatorów Python 3 na starszych obrazach Python 2
  • potwierdzenie przed startem zewnętrznych instalatorów i bezpieczna obsługa haseł systemowych
  • nowy mechanizm instalacji ZIP z weryfikacją archiwum przed rozpakowaniem
  • automatyczna próba doinstalowania unzip, jeśli brakuje go w systemie
  • bezpieczniejsza obsługa procesów i timeoutów w Python 2 / Python 3
  • mniej wymuszonych restartów po instalacji i po pracy Super Konfiguratora
  • zachowane funkcje oscam.dvbapi Poland oraz poprawki Backup/Restore list kanałów

Pełna lista zmian 12.0.4 → 12.0.6

Stabilność i bezpieczeństwo

  • wyłączono zadania startowe wtyczki przy uruchamianiu GUI Enigma2, co mocno ogranicza ryzyko bootloopa
  • dodano blokadę architektury Python oraz monit przed uruchamianiem zewnętrznych instalatorów
  • funkcja set_system_password korzysta z _safe_shell_arg(), dzięki czemu poprawnie obsługuje znaki specjalne
  • usunięto zbędny wpis WHERE_SESSIONSTART z lekkiego pliku plugin.py

Instalacja i technika

  • nowy katalog extract i weryfikacja ZIP przed właściwą instalacją
  • ochrona przed pustymi lub uszkodzonymi archiwami ZIP
  • bezpieczniejsze timeouty w _run_shell_capture dla Py2 i Py3
  • lepszy odczyt plików, kontrola getDesktop(0) i bezpieczniejszy fallback SSL / wget / curl

Mniej restartów i porządki

  • AIO Panel nie wymusza już automatycznego restartu po instalatorach uruchamianych z menu
  • Super Konfigurator nie wymaga pełnego restartu systemu po zakończeniu pracy
  • instalator installer.sh pobierany z GitHub nie wykonuje już automatycznego rebootu
  • czyszczone są pozostałości po starej lokalizacji wtyczki oraz pliki .pyc i .pyo

Co zostaje

  • zachowano funkcję oscam.dvbapi wraz z aktualizacją pakietu Poland
  • Backup/Restore list kanałów pozostaje aktywny i nadal działa bezpiecznie
  • główna klasa została przemianowana z Panel na PanelAIO
  • AIOLoadingScreen wywołuje teraz poprawnie nową klasę PanelAIO

Zdjęcia / podgląd

Instalacja przez terminal

Instalator AIO Panel — polecenie podstawowe
wget -q -O - https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Domyślna komenda dla użytkownika.

Instalator AIO Panel — wariant OpenPLi / problemy z GitHub
wget -q -O - --user-agent="Enigma2" -4 https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Użyj tylko gdy zwykłe pobieranie z GitHuba nie działa.

Instalacja pobranego IPK przez FTP

Jeśli pobierasz paczkę ręcznie: wgraj plik IPK do katalogu /tmp, a potem wykonaj instalację w terminalu.

Instalacja IPK z /tmp
opkg install /tmp/nazwa_paczki.ipk
