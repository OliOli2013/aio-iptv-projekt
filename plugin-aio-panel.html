Panel główny • aktualizacja 13.0.3

AIO Panel 13.0.3

Nowa wersja AIO Panel 13.0.3 dla Enigma2. Aktualizacja usprawnia Super Konfigurator, układanie i sortowanie list kanałów oraz naprawia funkcję Restore list kanałów.

Pobierz IPKWróć do wtyczek

Do czego służy

AIO Panel to panel narzędziowy dla Enigma2. Pozwala z jednego miejsca uruchamiać instalatory wtyczek, list kanałów, softcamów, piconów, skór, narzędzi systemowych oraz funkcji naprawy i aktualizacji.

Wydanie 13.0.3 usprawnia obsługę list kanałów i naprawia funkcję Restore, aby przywracanie list nie naruszało ustawień tunera, sieci, głowic ani pozostałej konfiguracji systemu.

Plik: enigma2-plugin-extensions-panelaio_13.0.3_all.ipk 211.9 KB

Najważniejsze zmiany w 13.0.3

  • Super Konfigurator instaluje teraz listę AIO Team 13E + 19.2E
  • poprawiono układanie i sortowanie list kanałów
  • naprawiono funkcję Restore list kanałów
  • przywracanie list nie powinno już naruszać ustawień tunera, sieci, głowic ani konfiguracji systemu
  • pozostałe funkcje AIO Panel pozostają bez zmian

Changelog 13.0.3

Super Konfigurator

  • domyślnie instaluje teraz listę AIO Team dla pozycji Hot Bird 13°E + Astra 19.2°E
  • zmiana dotyczy listy wybieranej podczas automatycznej konfiguracji tunera

Listy kanałów

  • poprawiono sposób układania dostępnych list kanałów
  • poprawiono ich sortowanie, aby aktualne pozycje były prezentowane w prawidłowej kolejności

Restore list kanałów

  • naprawiono mechanizm przywracania kopii list kanałów
  • Restore przywraca dane związane z listami kanałów, bez resetowania pozostałej konfiguracji Enigma2
  • ustawienia sieci, głowic, tunera i systemu nie powinny być naruszane

Aktualizacja

  • aktualizacja jest dostępna bezpośrednio z poziomu AIO Panel
  • pozostałe funkcje wtyczki pozostają bez zmian
  • po aktualizacji zalecany jest ręczny Restart GUI

Zdjęcia / podgląd

Aktualizacja i instalacja

Aktualizacja dostępna jest bezpośrednio z poziomu wtyczki AIO Panel. Wejdź w AIO Panel, użyj opcji aktualizacji, a po zakończeniu wykonaj ręczny Restart GUI.

Instalator AIO Panel — polecenie podstawowe
wget -q -O - https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Domyślna komenda dla użytkownika.

Instalator AIO Panel — wariant OpenPLi / problemy z GitHub
wget -q -O - --user-agent="Enigma2" -4 https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Użyj tylko wtedy, gdy zwykłe pobieranie z GitHuba nie działa.

Instalacja pobranego IPK przez FTP

Jeśli pobierasz paczkę ręcznie: wgraj plik IPK do katalogu /tmp, a potem wykonaj instalację w terminalu.

Instalacja IPK z /tmp
opkg install /tmp/enigma2-plugin-extensions-panelaio_13.0.3_all.ipk
