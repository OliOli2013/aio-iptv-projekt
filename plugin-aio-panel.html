Najważniejsza wtyczka

Co robi ta wtyczka?

Uniwersalny panel administracyjny dla Enigma2: listy kanałów, softcamy, instalatory, backup/restore, diagnostyka i aktualizacje z GitHuba.

  • Softcamy: dodano funkcję oscam.dvbapi – aktualizacja Poland.
  • Do paczki dodano lokalny plik oscam.dvbapi.poland.
  • Przed podmianą oscam.dvbapi tworzona jest kopia starego pliku.
  • Po aktualizacji wykonywane jest odświeżenie Softcam/Oscam.
  • Backup list kanałów ma lepszy wybór miejsca zapisu, kopię z datą i stały plik aio_channels_backup.tar.gz.
  • Restore list kanałów waliduje archiwum, tworzy awaryjną kopię obecnych list i przywraca dane osobnym skryptem po zatrzymaniu GUI.
  • Pozostałe działające funkcje wtyczki nie były zmieniane.
Kompatybilność: Enigma2 Python 2 / Python 3, OpenATV, OpenPLi i inne obrazy Enigma2.

Instalacja

Terminal, OpenWebif albo FTP

Najczyściej: pobierz IPK, wgraj przez FTP do /tmp, potem wykonaj instalację z terminala.

FTP + lokalny IPK

  1. Pobierz plik IPK z tej strony.
  2. Połącz się FTP z tunerem.
  3. Wgraj plik do katalogu /tmp.
  4. W terminalu wykonaj:
Instalacja pliku z /tmp
opkg install /tmp/enigma2-plugin-extensions-panelaio_12.0.3_all.ipk
killall -9 enigma2

Wget z adresu strony

Gdy tuner ma dostęp do internetu, możesz pobrać paczkę bezpośrednio.

Pobierz i zainstaluj
wget -O /tmp/aio-panel.ipk https://aio-iptv.pl/pliki/enigma2-plugin-extensions-panelaio_12.0.3_all.ipk && opkg install /tmp/aio-panel.ipk && killall -9 enigma2
Instalacja jednym poleceniem
wget -q -O - https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh
