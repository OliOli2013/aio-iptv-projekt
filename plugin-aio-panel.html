AIO Panel 13.0.2

Poprawiona wersja AIO Panel 13.0.2 dla Enigma2. Aktualizacja została przygotowana głównie z myślą o użytkownikach OpenPLi, u których pojawiały się problemy z pobieraniem i instalacją list kanałów oraz niektórych dodatków z GitHub.

Pobierz IPKWróć do wtyczek

Do czego służy

AIO Panel to panel narzędziowy dla Enigma2. Pozwala z jednego miejsca uruchamiać instalatory wtyczek, list kanałów, softcamów, piconów, skór, narzędzi systemowych oraz funkcji naprawy i aktualizacji.

Wydanie 13.0.2 jest aktualizacją naprawczą. Poprawia działanie na OpenPLi, instalację list kanałów, pobieranie dodatków online oraz bezpieczeństwo instalacji list.

Plik: enigma2-plugin-extensions-panelaio_13.0.2_all.ipk 212.1 KB

Najważniejsze zmiany w 13.0.2

  • poprawiono działanie AIO Panel na OpenPLi
  • poprawiono instalację list kanałów
  • po instalacji listy AIO wykonuje teraz odświeżenie list i bukietów
  • poprawiono pobieranie dodatków online
  • zwiększono bezpieczeństwo instalacji list kanałów
  • pozostałe funkcje AIO Panel pozostają bez zmian

Changelog 13.0.2

OpenPLi

  • poprawiono kompatybilność działania AIO Panel na obrazach OpenPLi
  • poprawiono obsługę pobierania plików z GitHub w przypadkach, gdy standardowe pobieranie sprawiało problemy
  • poprawki dotyczą przede wszystkim list kanałów oraz wybranych dodatków online

Listy kanałów

  • poprawiono mechanizm instalacji list kanałów
  • po prawidłowej instalacji listy wykonywane jest odświeżenie list i bukietów
  • obecna lista kanałów nie powinna zostać usunięta, jeśli nowa lista nie zainstaluje się prawidłowo

Dodatki online

  • poprawiono pobieranie dodatków online z poziomu AIO Panel
  • instalacja dodatków powinna działać stabilniej na obrazach, które mają problem z bezpośrednim pobieraniem z GitHub

Bezpieczeństwo instalacji

  • zwiększono zabezpieczenia podczas instalacji list kanałów
  • instalacja powinna ograniczyć ryzyko utraty aktualnej listy w razie nieudanego pobrania lub błędu instalacji
  • po aktualizacji zalecany jest ręczny Restart GUI

Zdjęcia / podgląd

Aktualizacja i instalacja

Aktualizacja dostępna jest bezpośrednio z poziomu wtyczki AIO Panel. Wejdź w AIO Panel, użyj opcji aktualizacji, a po zakończeniu wykonaj ręczny Restart GUI.

Instalator AIO Panel — polecenie podstawowe
wget -q -O - https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Domyślna komenda dla użytkownika.

Instalator AIO Panel — wariant OpenPLi / problemy z GitHub
wget -q -O - --user-agent="Enigma2" -4 https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh

Użyj tylko wtedy, gdy zwykłe pobieranie z GitHuba nie działa.

Instalacja pobranego IPK przez FTP

Jeśli pobierasz paczkę ręcznie: wgraj plik IPK do katalogu /tmp, a potem wykonaj instalację w terminalu.

Instalacja IPK z /tmp
opkg install /tmp/enigma2-plugin-extensions-panelaio_13.0.2_all.ipk
