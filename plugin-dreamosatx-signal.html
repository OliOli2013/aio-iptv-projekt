Do czego służy

DreamosatX Signal PL pomaga przy ustawianiu anteny i analizie sygnału na tunerze Enigma2.

Kompatybilność: DreamOS i większość obrazów Enigma2.

Najważniejsze funkcje

  • parametry sygnału
  • pomoc przy ustawianiu anteny
  • polski opis
  • szybka instalacja przez IPK

Podgląd / informacja

Instalacja przez terminal

Instalacja IPK
wget -O /tmp/enigma2-plugin-extensions-dreamosatxsignal_2.0+pl2_all.ipk https://aio-iptv.pl/pliki/enigma2-plugin-extensions-dreamosatxsignal_2.0+pl2_all.ipk && opkg install /tmp/enigma2-plugin-extensions-dreamosatxsignal_2.0+pl2_all.ipk && init 4 && sleep 2 && init 3
