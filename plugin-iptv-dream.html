IPTV / MAC / Xtream

Co robi ta wtyczka?

Wtyczka IPTV do list M3U, Xtream Codes oraz MAC Portal z eksportem kanałów do bukietów Enigma2 i wygodniejszym WebIF.

  • Obsługa M3U URL/plik, Xtream Codes i MAC Portal.
  • Eksport kanałów do bukietów Enigma2.
  • Instalacja źródeł EPG Import i praca z pikonami.
  • Wygodny WebIF do wprowadzania danych z telefonu lub komputera.
  • Wersja 6.5.1 porządkuje wpisy MAC, normalizuje formaty adresów i synchronizuje GUI z WebIF.
  • Updater GitHub korzysta z logiki SemVer i dokładniej wykrywa realne aktualizacje.
  • Kontakt wsparcia we wtyczce: aio-iptv@wp.pl.
Kompatybilność: Enigma2 Python 3, testowane głównie na współczesnych obrazach Enigma2.

Pobierz IPK
Instalacja

Terminal, OpenWebif albo FTP

Najczyściej: pobierz IPK, wgraj przez FTP do /tmp, potem wykonaj instalację z terminala.

FTP + lokalny IPK

  1. Pobierz plik IPK z tej strony.
  2. Połącz się FTP z tunerem.
  3. Wgraj plik do katalogu /tmp.
  4. W terminalu wykonaj:
Instalacja pliku z /tmp
opkg install /tmp/enigma2-plugin-extensions-iptvdream_6.5.1_all.ipk
killall -9 enigma2

Wget z adresu strony

Gdy tuner ma dostęp do internetu, możesz pobrać paczkę bezpośrednio.

Pobierz i zainstaluj
wget -O /tmp/iptv-dream.ipk https://aio-iptv.pl/pliki/enigma2-plugin-extensions-iptvdream_6.5.1_all.ipk && opkg install /tmp/iptv-dream.ipk && killall -9 enigma2
