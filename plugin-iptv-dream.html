Duża przebudowa • wersja 7.0.0

📺 IPTV Dream v7.0.0

Nowa, znacząco przebudowana wersja wtyczki IPTV dla Enigma2. Poprawiono stabilność, zgodność z różnymi serwerami, pobieranie i parsowanie list M3U, obsługę Xtream Codes i portali MAC oraz szybki eksport bukietów.

Pobierz IPK 7.0.0Instalacja z GitHubaWróć do wtyczek
To nie jest drobna poprawka. Wersja 7.0.0 przebudowuje najważniejsze mechanizmy odpowiedzialne za listy M3U, połączenia z serwerami, portale MAC oraz tworzenie bukietów. Wszystkie dotychczasowe funkcje zostały zachowane.

Obsługiwane źródła i funkcje

  • M3U z adresu URL
  • M3U z pliku
  • Xtream Codes
  • MAC Portal / Stalker / MAG / eStalker
  • ulubione oraz zarządzanie źródłami
  • eksport kanałów do bukietów Enigma2
  • EPG i picony
  • Web Interface na porcie 9999
  • statystyki i aktualizacje z poziomu wtyczki

Plik i zgodność

Wersja: 7.0.0

Plik: enigma2-plugin-extensions-iptvdream_7.0.0_all.ipk — 317.7 KB

Autor: by Paweł Pawełek

Dostępność: plik IPK, instalator GitHub oraz AIO Panel.

Po instalacji lub aktualizacji zalecany jest Restart GUI.

Przebudowane pobieranie i parser M3U

  • przebudowano mechanizm pobierania list M3U
  • poprawiono obsługę błędów HTTP 884, RemoteDisconnected i zerwanych połączeń
  • dodano obsługę serwerów zwracających błędny typ text/html
  • wtyczka sprawdza faktyczną zawartość odpowiedzi zamiast odrzucać listę wyłącznie na podstawie nagłówka serwera
  • poprawiono zgodność ze źródłami, które działają prawidłowo w XStreamity
  • przebudowano parser M3U oraz obsługę group-title, tvg-id, tvg-logo i EXTGRP
  • poprawiono nazwy kanałów zawierające przecinki, nietypowe znaki i niestandardowe metadane

Xtream Codes i portale MAC

Xtream Codes

  • przebudowano obsługę kont Xtream Codes
  • poprawiono zgodność z różnymi implementacjami API
  • ograniczono błędy podczas ładowania kategorii i kanałów

MAC / Stalker / MAG

  • przebudowano obsługę portali MAC, Stalker, MAG i eStalker
  • ograniczono timeouty oraz liczbę niepotrzebnych prób połączenia
  • przyspieszono ładowanie danych z portali MAC
  • poprawiono usuwanie zapisanych portali

Eksport bukietów, EPG i bezpieczeństwo

  • przywrócono szybki eksport bukietów bez zatrzymywania się na 0%
  • poprawiono tworzenie i bezpieczne zapisywanie plików bukietów
  • poprawiono referencje kanałów wykorzystywane przez EPG i picony
  • zwiększono ochronę przed błędami powodującymi niebieski ekran lub restart GUI
  • zachowano dotychczasowe funkcje zarządzania, ulubionych, WebIF, statystyk i aktualizacji

Ważne ograniczenia

Wtyczka może poprawić obsługę protokołów, parserów i błędów połączenia, ale nie naprawi problemów znajdujących się po stronie dostawcy. Wygasłe konto, martwy link, błędne dane dostępowe, blokada adresu IP albo niedziałający serwer nadal uniemożliwią pobranie i odtwarzanie kanałów.

Instalacja i aktualizacja

IPTV Dream v7.0.0 można zainstalować z pliku IPK, bezpośrednio z GitHuba albo z poziomu AIO Panel.

IPTV Dream — instalacja z GitHuba
wget -q -O - https://raw.githubusercontent.com/OliOli2013/IPTV-Dream-Plugin/main/installer.sh | /bin/sh

Po zakończeniu instalacji wykonaj Restart GUI.

Wariant OpenPLi / problemy z pobieraniem GitHub
wget -q -O - --user-agent="Enigma2" -4 https://raw.githubusercontent.com/OliOli2013/IPTV-Dream-Plugin/main/installer.sh | /bin/sh

Instalacja pobranego IPK przez FTP

Wgraj plik IPK do katalogu /tmp, a następnie wykonaj polecenie:

Instalacja IPK z /tmp
opkg install /tmp/enigma2-plugin-extensions-iptvdream_7.0.0_all.ipk
