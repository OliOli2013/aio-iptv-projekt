Instalacja IPK przez FTP

Najprostsza alternatywa dla one-linera.

01Pobierz IPKUżyj działu Wtyczki albo Centrum pobierania.
02Wgraj przez FTPSkopiuj plik do katalogu /tmp tunera.
03ZainstalujUżyj opkg install /tmp/nazwa.ipk.
04Restart GUIJeśli instalator tego wymaga, uruchom ponownie Enigma2.

Instalacja jednego IPK

FTP / IPK
opkg install /tmp/nazwa_paczki.ipk

Instalacja wszystkich IPK z /tmp

FTP / IPK
opkg install /tmp/*.ipk

Podstawowe komendy serwisowe

Szybka diagnostyka i podstawowa obsługa systemu.

Restart GUI

SERWIS
init 4 && sleep 2 && init 3

Odświeżenie pakietów

SERWIS
opkg update

Sprawdzenie miejsca

SERWIS
df -h

Ostatnie logi systemowe

SERWIS
logread | tail -n 100

Nasłuchujące porty

SERWIS
netstat -tlnp | grep LISTEN || ss -tlnp

Wersja Pythona

SERWIS
python --version 2>&1 || python3 --version
