Czytelne polecenia FTP, OpenWebif i terminala

Ta strona ma być praktyczna: pobierz IPK, wgraj przez FTP do /tmp, uruchom jedną komendę i wykonaj restart GUI.

Szybki dostęp do plików, poradników i instalacji.

FTP krok po kroku

Najprostszy schemat instalacji IPK

1

Pobierz IPK

Na stronie wtyczki kliknij „Pobierz IPK”.

2

Połącz FTP

Host: IP tunera, port: 21, użytkownik zwykle root.

3

Wgraj do /tmp

Skopiuj paczkę IPK do katalogu /tmp.

4

Zainstaluj

W OpenWebif Terminal / SSH wykonaj opkg install /tmp/*.ipk.

Gotowe polecenia

Kopiuj i wklej w terminalu

Instalator AIO Panel z GitHuba
wget -q -O - https://raw.githubusercontent.com/OliOli2013/PanelAIO-Plugin/main/installer.sh | /bin/sh
Instalacja dowolnej paczki IPK z /tmp
opkg install /tmp/*.ipk
killall -9 enigma2
Odświeżenie listy pakietów
opkg update
Restart GUI
init 4 && sleep 2 && init 3
Sprawdzenie miejsca
df -h
Logi po błędzie
logread | tail -n 100
Sprawdzenie portu WebIF / usługi
netstat -tlnp | grep LISTEN || ss -tlnp
Instalacja SoftCam feed OpenATV
wget -O - -q http://updates.mynonpublic.com/oea/feed | bash
opkg update
