One‑Liner / FTP

Komendy do terminala i FTP

Gotowe polecenia dla osób, które chcą szybko zainstalować IPK, sprawdzić tuner albo wykonać prostą diagnostykę.

Instalacja AIO PanelDiagnostyka

Komendy do skopiowania

Instalacja IPK z /tmp
opkg install /tmp/nazwa_paczki.ipk
Instalacja AIO Panel
wget -O /tmp/aio-panel.ipk https://aio-iptv.pl/pliki/enigma2-plugin-extensions-panelaio_12.0.3_all.ipk && opkg install /tmp/aio-panel.ipk && init 4 && sleep 2 && init 3
Restart GUI
init 4 && sleep 2 && init 3
Awaryjny restart Enigma2
killall -9 enigma2
Odświeżenie pakietów
opkg update
Sprawdzenie miejsca
df -h
Ostatnie logi
logread | tail -n 100
Test internetu
ping -c 4 1.1.1.1
Lista nasłuchujących portów
netstat -tlnp | grep LISTEN || ss -tlnp
Backup list kanałów
tar -czf /tmp/backup-list-kanalow.tar.gz /etc/enigma2/lamedb* /etc/enigma2/bouquets.* /etc/enigma2/userbouquet.*

FTP: gdzie wgrywać pliki

IPK: wgraj do /tmp, potem wykonaj opkg install /tmp/nazwa.ipk.

Picony: najczęściej /usr/share/enigma2/picon.

Listy kanałów: pliki Enigma2 trafiają zwykle do /etc/enigma2. Przed podmianą zrób backup.
