Centrum diagnostyki i bezpiecznej naprawy

🩺 E2 Doctor 2.3

Codzienne narzędzie dla dekoderów Enigma2 z Pythonem 3. Sprawdza kondycję tunera, wykrywa problemy, wyjaśnia ich możliwe przyczyny i — tam, gdzie jest to bezpieczne — pozwala uruchomić odpowiednie działanie naprawcze.

Pobierz IPK 2.3Instalacja z GitHubWróć do wtyczek

Centrum kondycji tunera

E2 Doctor pokazuje ogólną kondycję dekodera w skali 0–100, liczbę prawidłowych wyników, informacji, ostrzeżeń i błędów. Najważniejsze problemy są wyróżniane, aby użytkownik od razu wiedział, od czego zacząć.

Każdy moduł ma własny piktogram, krótki opis i czytelne oznaczenie statusu. Wtyczka została przygotowana jako praktyczne narzędzie do regularnej kontroli systemu, a nie tylko jednorazowy skaner.

Informacje o wydaniu

Wersja: 2.3
Wymagania: Enigma2 Python 3
Autor: by Paweł Pawełek
Kontakt: aio-iptv@wp.pl

Plik: enigma2-plugin-extensions-e2doctor_2.3_all.ipk — około 262 KB

Każda operacja wymagająca zmian musi zostać zatwierdzona przez użytkownika. E2 Doctor nie przywraca ustawień fabrycznych i nie usuwa konfiguracji tunera.

Co sprawdza E2 Doctor?

  • system, wersję obrazu i Pythona
  • pamięć flash, RAM, CPU i temperaturę
  • połączenie sieciowe, adres IP, DNS i HTTPS
  • listy kanałów, lamedb i odwołania do bukietów
  • głowice, konfigurację tunerów i bieżący sygnał
  • dyski, pendrive’y i punkty montowania
  • menedżer pakietów OPKG
  • działanie OSCam
  • EPG i picony
  • zainstalowane wtyczki pod kątem zgodności z Pythonem 3
  • crashlogi Enigma2 wraz z próbą wskazania źródła błędu

Pomoc i bezpieczna naprawa

Po wejściu w wykryty problem E2 Doctor pokazuje, co zostało wykryte, możliwą przyczynę, konsekwencje problemu, instrukcję postępowania krok po kroku oraz dostępne bezpieczne działania.

Porządkowanie i pamięć

  • oczyszczenie starych crashlogów i plików tymczasowych
  • sprawdzenie największych plików zajmujących pamięć flash
  • odświeżenie pamięci RAM bez zatrzymywania procesów

System i usługi

  • usunięcie nieaktywnej blokady OPKG
  • ponowne uruchomienie OSCam
  • wykonanie rozszerzonego testu sieci
  • tymczasowe wyłączenie podejrzanej wtyczki

Listy kanałów

  • naprawa brakujących odwołań do bukietów
  • przeładowanie listy kanałów

Diagnostyka

  • przygotowanie pełnego raportu diagnostycznego
  • analiza crashlogów i próba wskazania źródła problemu

Język polski i angielski

Domyślnie E2 Doctor korzysta z języka systemu:

  • 🇵🇱 polski system — interfejs polski
  • 🇬🇧 każdy inny język systemu — interfejs angielski

Język można również ustawić ręcznie w ustawieniach wtyczki.

Aktualizacja z GitHub i weryfikacja paczki

E2 Doctor posiada własny moduł aktualizacji. Wtyczka sprawdza dostępność nowej wersji, pobiera paczkę z GitHub i przed instalacją weryfikuje jej sumę SHA-256.

Zdjęcie / podgląd

Instalacja bezpośrednio z GitHub

Polecenie wklej w terminalu SSH, Telnet lub konsoli dekodera. Po instalacji wykonaj restart GUI Enigma2.

E2 Doctor 2.3 — instalator GitHub
wget -q -O - https://raw.githubusercontent.com/OliOli2013/E2-Doctor-Plugin/main/installer.sh | /bin/sh

Instalator pobiera aktualne wydanie z repozytorium projektu.

Instalacja pobranego IPK przez FTP

Wgraj plik IPK do katalogu /tmp, a następnie wykonaj poniższe polecenie w terminalu.

Instalacja IPK z /tmp
opkg install /tmp/enigma2-plugin-extensions-e2doctor_2.3_all.ipk

Po zakończeniu instalacji wykonaj restart GUI Enigma2.
