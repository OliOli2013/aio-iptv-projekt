# AIO-IPTV.pl — paczka strony

Paczka zawiera uporządkowany serwis GitHub Pages dla AIO-IPTV.pl.

## Wdrożenie

1. Rozpakuj paczkę ZIP.
2. Wgraj zawartość do głównego katalogu repozytorium GitHub Pages.
3. Nadpisz istniejące pliki.
4. Zachowaj katalog `pliki/`, bo zawiera IPK, grafiki i materiały do pobrania.

## Główne działy

- Start
- Moje wtyczki
- Poradniki
- Multi-Click i systemy
- Listy kanałów
- One-Liner / FTP
- Kontakt / wsparcie / statystyki
- AI Chat
