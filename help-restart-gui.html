Restart GUI

Restart GUI bez restartu tunera

Restart GUI przeładowuje interfejs Enigma2 bez pełnego rebootu tunera. Używa się go po instalacji wtyczek, skina, piconów albo zmianach w konfiguracji.

  • Najbezpieczniejsza komenda: init 4 && sleep 2 && init 3.
  • Awaryjnie można użyć killall -9 enigma2.
  • Przy nagrywaniu sprawdź najpierw, czy restart GUI nie przerwie pracy.
Restart GUI
init 4 && sleep 2 && init 3
Awaryjny restart Enigma2
killall -9 enigma2
