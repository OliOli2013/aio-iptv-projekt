# Security policy / Zgłaszanie luk bezpieczeństwa

## Zgłoszenia / Vulnerability reports

Prosimy **nie publikować** informacji o potencjalnej luce, tokenów, danych kont ani instrukcji ataku w publicznych GitHub Issues, komentarzach ani na forum.

**Kanał zgłoszeń:** [formularz kontaktowy AIO](https://aio-iptv-projekt.pages.dev/contact.html) lub wiadomość na **aio-iptv@wp.pl** z tematem `SECURITY AIO`.

Opisz: dotknięty adres/funkcję, sposób bezpiecznego odtworzenia problemu, jego wpływ, przybliżoną datę oraz minimalny przykład *bez prawdziwych danych użytkowników*. Nie testuj cudzych kont, nie pobieraj danych i nie przeprowadzaj obciążających testów bez uzgodnienia.

Raport zostanie przeanalizowany. Ewentualne działania naprawcze i publikacja szczegółów powinny zostać skoordynowane z administracją.

**English:** Please report security issues privately via [AIO contact](https://aio-iptv-projekt.pages.dev/contact.html) or **aio-iptv@wp.pl** (subject `SECURITY AIO`). Include affected endpoint, impact, and non-destructive reproduction steps. Do not expose real user data or publish proof-of-concept details before coordination.

## Zakres / Scope

Dotyczy bieżącej wersji strony AIO TunerHub, backendu Cloudflare Pages Functions oraz używanych funkcji D1/R2. Historyczne pliki i zewnętrzne instalatory należy zgłaszać do ich właściwych opiekunów, jeżeli nie są utrzymywane przez AIO.

## Poufność / Privacy

Nie wysyłaj haseł, kluczy API, pełnych identyfikatorów sesji, kopii prywatnych baz ani danych innych użytkowników. Jeśli istnieje ryzyko wycieku, najpierw skontaktuj się z administracją w celu uzgodnienia bezpiecznego kanału.
